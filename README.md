## 📖 Tentang Project

**ShaSkin Beauty Care** adalah aplikasi web untuk sistem reservasi dan booking pada klinik kecantikan. Website ini memungkinkan pasien untuk:

- 📅 Membuat janji temu dengan dokter
- 👨‍⚕️ Melihat profil dokter dan jadwal praktik
- 💅 Memilih layanan perawatan kulit & estetika
- 🔔 Menerima notifikasi appointment
- 📊 Melihat riwayat kunjungan

## 🚀 Quick Start

```bash
# Clone repository
git clone https://github.com/yourusername/Kelompok_2.git

# Masuk ke direktori project
cd Kelompok_2/Web/sskinv0.5.9\ \(LocalHost\)

# Install dependencies
composer install

# Setup database
# Import file edoc.sql ke MySQL

# Jalankan server
php -S localhost:8000
```

> 📚 Untuk panduan lengkap, lihat [SETUP_LOCALHOST.md](Web/sskinv0.5.9%20(LocalHost)/SETUP_LOCALHOST.md)
